LLM Blocker Classification

✓
No Blocker (Green) — Directly transferable to LLM: entirely virtual (code, text, analysis)
~
Soft Blocker (Yellow) — Requires slight modification: pre-fetching from sandboxed portal or proprietary source
✗
Hard Blocker (Red) — Non-transferable to LLM: physical presence, human relationship, expert judgment with fiduciary liability

Flowchart Symbol Conventions

Oval (Stadium) — Start or end of process
Rectangle — Process or operation step
Diamond — Decision point (yes/no branch)
Parallelogram — Input or output operation

RACI Matrix — Financial Model Build
33 steps · R=Responsible · A=Accountable · C=Consulted · I=Informed
RACI R — Responsible A — Accountable C — Consulted I — Informed LA=Lead Analyst  ·  AS=Associate  ·  RD=Research Director  ·  SA=Supervisory Analyst  ·  CO=Compliance
# Step (Verb + Object) Actor Shape Blocker LA AS RD SA CO
Phase 1 — Setup & Data Collection
1 Define model scope (segments, horizon, metrics) LA ▭ Rect Soft R A
2 Source 5-year historical financials from SEC EDGAR AS ▱ Para Soft A R
3 Download earnings call transcripts (min 8 quarters) AS ▱ Para Soft A R
4 Pull consensus estimates from FactSet / Bloomberg AS ▱ Para Soft A R
5 Extract IR KPI supplements and earnings presentation decks AS ▱ Para Soft A R
Phase 2 — Historical Model Build
6 Build master workbook architecture (IS / BS / CF / KPI / Valuation tabs) AS ▭ Rect None A R
7 Populate historical income statement by segment (5 years) AS ▭ Rect None A R
8 Compute GAAP-to-adjusted P&L reconciliation with source citations AS ▭ Rect None A R
9 Build historical balance sheet (working capital, goodwill, debt, equity) AS ▭ Rect None A R
10 Build cash flow statement from IS and BS movements AS ▭ Rect None A R
11 Calculate historical KPIs and operating ratios (margins, turns, ROIC) AS ▭ Rect None A R
12 Audit all data ties back to SEC filings line by line LA ▭ Rect Soft R C A
G1 Decision: Data errors or gaps found? LA ◇ Diamon Soft A
Phase 3 — Management Input & Assumptions
13 Conduct IR / management call for operating context and guidance color LA ▭ Rect Hard ✗ R A I
G2 Decision: MNPI received inadvertently? LA / CO ◇ Diamon Hard ✗ C A
— ⚠ CO: Halt model work; escalate MNPI to Compliance [branch — not modeled further] CO ▭ Rect Hard ✗ I I A
14 Review management guidance and sell-side consensus range LA ▭ Rect Soft R C A
15 Set revenue assumptions by segment (price drivers × volume drivers) LA ▭ Rect Soft R A
16 Set margin, D&A, CapEx, and working capital assumptions LA ▭ Rect Soft R A
Phase 4 — Forward Model Build
17 Build forward income statement (3–5 year projection) AS ▭ Rect None A R
18 Build forward balance sheet with debt amortization schedule AS ▭ Rect None A R
19 Build forward FCF model (OCF, CapEx, NWC changes, levered/unlevered) AS ▭ Rect None A R
20 Populate sector-specific KPI projections (SSS / ARPU / RevPAR / NRR) AS ▭ Rect None A R
Phase 5 — Valuation
21 Build DCF model (WACC, explicit period, GGM terminal value) LA ▭ Rect None R C A
22 Build trading comparables table (8–15 peers, NTM EV/EBITDA, EV/Rev, P/E) AS ▭ Rect Soft A R
23 Build precedent transactions table (5–7 years, deal multiples, control premiums) AS ▭ Rect Soft A R
24 Derive and weight price target across all valuation methodologies LA ▭ Rect None R A
25 Build two-way sensitivity tables (WACC vs. growth; revenue vs. margin) AS ▭ Rect None A R
26 Build bull / base / bear scenario framework with distinct catalysts LA ▭ Rect None R C A
Phase 6 — Quality Control & Review
27 Run formula audit — cross-check all cell references and formulas AS ▭ Rect None A R
28 Review model for logical consistency and assumption coherence vs. sector context LA ▭ Rect Soft R C A
29 Conduct FINRA-required supervisory review (EPS tie, GAAP recon, PT methodology) SA ▭ Rect Hard ✗ I C C A
30 Formally challenge model assumptions and PT — route to rating committee if required RD ▭ Rect Hard ✗ C A C I
G3 Decision: Model and PT approved? RD ◇ Diamon Hard ✗ I A C
31 Revise challenged assumptions and rebuild affected model sections LA ▭ Rect Soft R C A
Phase 7 — Output & Handoff
32 Lock model and create version-controlled archive LA ▭ Rect None R C A
33 Export summary exhibits and charts for research report AS ▭ Rect None A R
34 Upload consensus estimates to Refinitiv IBES / Bloomberg / FactSet AS ▱ Para Soft A R I

Key Blocker Notes: Steps 2–5 are Soft (not Green) because they require pre-fetched access to proprietary portals: SEC EDGAR XBRL parsing needs setup, FactSet/Bloomberg terminals require credentialed API integration, and IR portal supplements require scraping or pre-download workflows. Steps 15–16 (assumption-setting) are Soft rather than Green because they require live calibration against proprietary consensus data and guidance not natively available to a raw LLM. Steps 13, 29–30 are Hard because they require human relationship capital (IR call), FINRA-licensed supervisory authority with fiduciary liability (SA review), and senior expert judgment with accountability for the published rating (RD sign-off).
